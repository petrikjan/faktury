# Stav místní implementace — 6. 11. 2026

**Probíhá nasazení na faktury.janpetrik.cz přes aaPanel Git Manager po pushi do main. Uživatel nasazení povolil, repozitář již vytvořil a pushnul.** Původní PHP a jeho veřejná doména zatím zůstávají aktivní. Oddělený Node projekt, checkout a nová prázdná DB jsou připravené; úvodní soukromá záloha původního systému je dokončená. Databázový export odpovídá původnímu importnímu baseline. Finální zastavení zápisů, přenos současné Node databáze a přepnutí domény dosud neproběhly.

Místní implementace obsahuje povolený import a všechny následné úpravy vlastníka. Čistě Node PDF má zachovat čitelné původní rozložení; pixelová identita není požadována. Testy na Node 26.13.0 / MariaDB 12.3.2 prošly: 62 aplikačních testů, 14 testů nasazení, typecheck, lint, build a 8 E2E scénářů. Zároveň prošla čistá instalace bez legacy a skutečných dat. Dva scénáře vystavení čekají na dokončení PDF až 20 sekund namísto původních pěti. Obsah skutečných záznamů se modelu nezobrazoval.

Mazání vyžaduje oba kroky i na serveru, faktury uchovávají předchozí verze a PDF. Smazané doklady se nepočítají do přehledů, uvolněná čísla se použijí přednostně ve stejném roce. Podrobnosti v HANDOVER.md. Nové E2E ověřují úpravy a smazání včetně historie.

## Místní prostředí

Cílové a ověřovací prostředí: Node 26.13.0, npm 11.9.0, MariaDB 12.3.2. Původní místní obchodní DB nadále používá oddělený server 11.4.13. PHP 8.5.12 je jen pro izolovanou syntetickou referenci. Produkční aplikace používá výhradně Node/Chromium, žádné PHP. Datadir je `.private/db`, DB poslouchá pouze na 127.0.0.1:3307. Účty/hesla a testové konfigurace jsou jen v ignorovaných souborech; do chatu se nevypisují. Náhled běží na http://localhost:5173 s importovanou databází, dostupnost a aktivní migrační značka byly zkontrolovány.

Syntetické testy používají oddělené databáze pro integrační, zdrojové DDL, E2E a obnovu. Produkční start nic neseeduje/importuje a požaduje výslovné schválení PDF přes PDF_REVIEW_APPROVED.

## Provozní hranice

PHP zdroj potvrzuje Europe/Prague, nikoli všechny historické souvislosti DB session. Zdrojový DATETIME se zachovává doslova. Aktuální nastavení není důkaz minulého DPH/adresy/účtu; import je označená rekonstrukce, nikoliv prokazatelný historický snímek. Datum úhrady importu zůstává NULL.

Aktuální dokumentace Maxnera dokládá Git Manager a webhook na `main`. Stejný postup je připraven pro Faktury: chráněný helper, oddělený release, syntetické kontroly bez produkčního `.env`, čtecí ověření migrací, nativní restart a DB/SHA readiness s návratem předchozího kódu při chybě. Automatické nasazení neprovádí import ani DDL. Konkrétní aaPanel je připojený a nativní rozhraní přečtené; první skutečné spuštění a přepnutí domény zbývá ověřit. Podrobnosti v DEPLOYMENT.md.

PDF bez uložené přílohy se při prvním náhledu nebo stažení lokálně vytvoří z uložených údajů a potvrzené DPH. Kopie je označená jako reconstructed, má audit a další požadavky použijí stejný soubor. Částky, položky a snímek se nemění. Název stažení je číslo faktury s příponou .pdf, také u historické verze podle jejího tehdejšího čísla. Ověřeno 58 aplikačními testy, osmi E2E scénáři a jedním skutečným místním vytvořením bez zobrazování obsahu modelu.
